# บันทึกขายซิม/เน็ตผ่าน LINE

พนักงานพิมพ์ในแชต LINE ของ FixITPro เช่น `dtac 250` ระบบจะบันทึกการขายเป็นชื่อพนักงานคนนั้น หักกระเป๋าค่ายให้ และตอบยอดคงเหลือกลับมา
ถ้าพนักงานพิมพ์ยอดที่แอปค่ายโชว์ด้วย เช่น `dtac 250 เหลือ 1200` แล้วยอดไม่ตรงกับในระบบ เจ้าของร้านจะได้รับแจ้งเตือนทันที

## ตั้งค่าครั้งเดียว (ผู้ดูแลระบบ FixITPro)

1. เข้า https://developers.line.biz/console/ แล้วเลือกบัญชี LINE OA ของ FixITPro (@fixitpro)
   ถ้ายังไม่มี Messaging API channel ให้เปิดใช้ก่อน: ไปที่ LINE Official Account Manager → ตั้งค่า → Messaging API → เปิดใช้งาน
2. ในหน้า channel:
   - **Basic settings** → คัดลอก **Channel secret**
   - **Messaging API** → **Channel access token (long-lived)** → กด **Issue** แล้วคัดลอก
3. เข้าเว็บ FixITPro ด้วยบัญชี Super Admin → **Settings** → กล่อง **LINE และคีย์ของระบบ**
   - ใส่ LINE OA ID (`@fixitpro`), Channel secret และ Channel access token แล้วกด **บันทึก**
   - คัดลอก **Webhook URL** จากกล่องเดียวกัน
4. กลับไปที่ LINE Developers → **Messaging API** → **Webhook URL**
   - วาง URL ที่คัดลอกมา แล้วกด **Verify**
   - เปิด **Use webhook**
5. ใน LINE Official Account Manager → **ตอบกลับอัตโนมัติ** → ปิดข้อความตอบกลับอัตโนมัติ เพื่อไม่ให้ตอบซ้ำกับระบบ

ค่าลับทั้งหมดใส่ผ่านหน้าเว็บ ไม่ต้องแก้อะไรบนเซิร์ฟเวอร์ หน้าเว็บจะไม่แสดงค่าที่ใส่ไปแล้วกลับมาอีก
ถ้ามีการตั้งตัวแปรชื่อเดียวกันไว้บนเซิร์ฟเวอร์แล้ว ระบบจะใช้ค่าบนเซิร์ฟเวอร์ก่อน

### ให้ระบบอ่านรูปหน้าจอแอปค่ายได้ (ไม่บังคับ)

- ใส่ **คีย์ AI** (Anthropic API key จาก https://console.anthropic.com) ในกล่องเดียวกัน
- มีค่าใช้จ่ายตามจำนวนรูปที่อ่าน ประมาณไม่กี่สิบสตางค์ต่อรูป
- ถ้าไม่ใส่ พนักงานยังพิมพ์ข้อความได้ตามปกติ

## พนักงานเริ่มใช้

1. เปิดหน้า **ขายซิม/แพ็กเกจ** (เว็บ) หรือ **เติมเน็ต / SIM** (แอป) → กด **เชื่อม LINE ของฉัน**
2. LINE จะเปิดแชตพร้อมข้อความ `เชื่อมบัญชี …` ให้กดส่ง (ลิงก์ใช้ได้ 30 นาที)
3. จากนั้นพิมพ์ได้เลย:

| พิมพ์ | ความหมาย |
|---|---|
| `dtac 250` | ขายเน็ต DTAC 250 บาท ลูกค้าจ่ายเงินสด |
| `ทรู 150 0812345678` | ใส่เบอร์ลูกค้าด้วย |
| `เติม ais 50` | เติมเงิน (ไม่ใช่แพ็กเกจ) |
| `dtac 250 เหลือ 1200` | ใส่ยอดที่แอปค่ายโชว์ ระบบจะเทียบให้ |
| `dtac 250 โอน` | ลูกค้าโอนเงิน |
| `dtac 250 ทุน 240` | ค่ายหักจริง 240 บาท (ถ้าไม่ใช่ 97% ตามปกติ) |
| `ยอด` | ดูยอดกระเป๋าทุกค่าย |
| ส่งรูปหน้าจอแอปค่าย | ระบบอ่านแล้วให้กด **บันทึก** ยืนยัน (ต้องใส่คีย์ AI ก่อน) |

เงื่อนไข:
- ต้องเปิดกะก่อน เหมือนการขายในหน้าเว็บ
- LINE ส่งข้อความซ้ำมา ระบบจะไม่บันทึกซ้ำ
- เจ้าของร้านและผู้จัดการที่เชื่อม LINE ไว้ จะได้รับแจ้งเตือนเมื่อยอดไม่ตรงหรือกระเป๋าในระบบไม่พอ

## ที่มาของปัญหาเงินไม่ตรง (ข้อมูลจริง ต.ค. 2026)

- ร้านเติมเงินเข้ากระเป๋า 1,600 บาท แต่มีการบันทึกขายในระบบแค่ 1 รายการ
- การขายส่วนใหญ่ทำในแอปค่ายแล้วไม่ได้บันทึกในระบบ ยอดในระบบเลยไม่ตรงกับแอปค่าย
- ช่องทาง LINE ทำให้การบันทึกเร็วขึ้น และการใส่ "เหลือ …" ช่วยให้จับรายการที่ไม่ได้บันทึกได้ในวันนั้นเลย
